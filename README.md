# Computer graphics course

Repository for my coursework and projects created during the **Computer Graphics** course.
It includes laboratory exercises and course projects related to **C++**, **OpenGL**, **SFML**, and **GLEW**.

## Requirements

- SFML 2.6.0 - [download here](https://www.sfml-dev.org/download/sfml/2.6.0/)
- GLEW 2.3.1 - [download here](https://sourceforge.net/projects/glew/files/glew/2.1.0/)
- Visual Studio 2022 or another compatible environment

## Repository structure

```text
labs/       - laboratory exercises and weekly assignments
projects/   - larger course projects
docs/       - notes, screenshots, and additional course materials
```

## Notes

This repository is intended for educational purposes and documents my progress during the course. This repository contains only source code and project structure.

External libraries and local build environment are configured separately on the machine, according to the setup instructions provided during the course.
